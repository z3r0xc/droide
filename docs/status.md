## Gates

A change is mergeable when all of these pass:

1. `npm run typecheck`
2. `npm run format:check`
3. `npm test`
4. `npm run test:parity` (local goldens present)
5. `npm run gaps:check`
6. `npm run brand:check`
7. `cargo test --workspace` (CI)
8. the spec clause it implements is cited in the commit message or the PR body
